# Notes for coding agents

Read [doc/README.md](doc/README.md) and the page matching the task before you start: conventions, testing, releases and provider research are there.

Keep what you learn about this project in `doc/`, not in an agent's memory: conventions, test setups, release steps, research results and decisions go into the matching page (or a new one, listed in `doc/README.md`), so every agent and person reads the same. The repository is public: private details such as key locations, device serials, accounts and passwords stay out of `doc/` and go into the agent's memory instead.
